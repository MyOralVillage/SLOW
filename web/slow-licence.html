Notes for the developer
  1. What to add. Insert the block in Section 2 into the profile sign-up form, above the submit button. It is self-contained: styles are prefixed slow-lic- so they should not clash with the site's CSS. Section 3 is an optional one-line licence notice for the footer of every SLOW page.
  2. Full legal code is built in. The complete CC BY-SA 4.0 legal code sits inside the block in a collapsed panel ("Read the full legal code"), styled in MOVE's Century Gothic with navy (#0B2545) section titles. The "legal code" and "CC BY-SA 4.0" links open that panel; no extra page needs to be hosted. Creative Commons dedicates its licence texts to the public domain (CC0), so reproducing them here is permitted. The panel also links to the official version on creativecommons.org. Please do not edit the legal code text.
  3. Font. The block asks for Century Gothic, falling back to similar geometric fonts (AppleGothic, URW Gothic) and then the device's default sans-serif. Century Gothic is installed on most Windows and Mac computers but not on Android phones, so many users in Sierra Leone will see the fallback unless a licensed Century Gothic web font is added to the site.
  4. Enforce on the server, not only in the browser. The checkbox is unticked by default and marked required, and a small script keeps the submit button disabled until it is ticked. Browser checks can be bypassed, so the server must also refuse to create a profile unless slow_licence_agree=yes is received.
  5. Keep a record of acceptance. For each profile, store the user ID, the date and time of acceptance, and the terms version (slow_terms_version, currently SLOW-CCBYSA4-v1). If the wording changes later, bump the version and ask users to accept again.
  6. Existing accounts. Anyone who already has a profile should be asked to accept on their next login before they can post or edit.
  7. Team-made work. Point 2 of the agreement now covers three cases: made by the uploader alone, made by a team whose members all agreed, or owned by an organization that agreed. No extra checkbox is needed; the wording itself covers teams.
  8. "Made by" field (upload form). Add the field in Section 4 to the form used to upload each item (slow_made_by). Store it with the item and show it on the item's page as "Made by: …". It can be edited, so every team member can be named. This is how the Attribution (BY) requirement is met for teams and partner organizations.
  9. Links. External links open in a new tab, so the person does not lose what they have typed in the form. Official URLs: deed https://creativecommons.org/licenses/by-sa/4.0/deed.en; legal code https://creativecommons.org/licenses/by-sa/4.0/legalcode.en.
  10. Footer. Add the notice in Section 3 to the footer of every SLOW page, in web/ and in the Android web view if it has its own footer.
